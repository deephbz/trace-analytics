How each harness compacts



Terms used below. Context before: the context size the harness reports when it compacts. Request input: the input tokens of the compaction request itself. Output: tokens the compaction request generated. Wall time: request start to compaction result. Context after: input tokens of the first model request after the compaction. Handoff turn: the extra agent turn that pi's hc-auto-compact runs before it compacts, so the agent can write durable notes. Cost: list price per token, applied also to subscription traffic. Agent turn: one user prompt (pi, Claude Code) or one Codex task.
